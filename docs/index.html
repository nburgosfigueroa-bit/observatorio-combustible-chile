¿Qué es este proyecto?

Herramienta de análisis construida con datos históricos oficiales de la Comisión Nacional de Energía (CNE), normalizados mediante un proceso ETL y modelados para Power BI.

Metodología

Extract: lectura de archivos históricos CNE.

Transform: auditoría, homologación, limpieza y normalización.

Load: DuckDB, Parquet y tablas analíticas mensuales.

Visualización: Power BI con modelo dimensional y medidas DAX.
